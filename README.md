# Python Calculator

A clean, beginner-friendly desktop calculator built with Python and Tkinter.

## Features

- Basic arithmetic: `+`, `-`, `*`, `/`
- Percentage and power operations
- Parentheses
- Scientific functions: `sqrt`, `sin`, `cos`, `tan`, `log`, `ln`, `abs`
- Constants: `pi` and `e`
- Calculation history
- Clear and backspace buttons
- Keyboard support: Enter, Escape, and Backspace
- Safe expression parsing using Python's `ast` module instead of `eval()`
- No external Python packages required

## How to Run

Make sure Python 3 is installed.

```bash
python3 calculator.py
```

On Windows:

```bash
python calculator.py
```

## Example Expressions

```text
25 + 15
100 / 4
2 ** 5
sqrt(144)
sin(90)
cos(0)
log(100)
ln(e)
(10 + 5) * 2
```
