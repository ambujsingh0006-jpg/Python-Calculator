# Project Notes

## Short explanation for college/resume

I built a Python-based desktop calculator using Tkinter. It supports normal arithmetic as well as scientific functions such as square root, trigonometric functions, logarithm, and powers. I also added calculation history, keyboard controls, input validation, and safe expression parsing using the AST module.
